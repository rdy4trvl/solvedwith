Turn bug reports into fix pull requests

Sentry's analysis hands the root cause to a Cursor cloud agent, which writes the fix and opens a PR.

What they did

When Sentry finds the root cause of an error, it passes the context to Cursor's agent. The agent writes a fix and opens a pull request in the repo.

How it went

Developers review and merge the PR, so nothing ships without a person.

Our read

Our analysis · Oct 28, 2026

Not from the source. Our own assessment of the approach, which may date as the tools change.

Where it falls down

  • A fix that stops the error is not always the right fix; it can mask the cause instead.
  • Review quality drops when plausible-looking PRs arrive steadily.
  • It only sees errors Sentry caught, so silent failures stay untouched.

Worth trying next

  • Require a failing test in the PR that the fix makes pass.
  • Track how many of these PRs are later reverted.
